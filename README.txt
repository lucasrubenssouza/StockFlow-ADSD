StockFlow - código de referência
Execução opcional em ambiente disponível:
1) python -m pip install -r requirements.txt
2) python app.py
3) abrir http://127.0.0.1:5000

O sistema StockFlow foi executado localmente utilizando Python, Flask e SQLite, com acesso pelo navegador em http://127.0.0.1:5000.

Foram realizados cinco testes funcionais:
- CT01: Cadastro de produto — aprovado.
- CT02: Validação de nome obrigatório pelo navegador — aprovado.
- CT03: Pesquisa de produto — aprovado.
- CT04: Atualização da quantidade em estoque — aprovado.
- CT05: Bloqueio de quantidade negativa pelo navegador — aprovado.

As evidências dos testes realizados estão documentadas no relatório acadêmico do Projeto Integrado Interdisciplinar.
